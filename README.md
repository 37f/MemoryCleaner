# 内存整理工具

一个简洁的 Windows 中文 GUI 工具，用 Windows 官方 API 整理当前登录用户进程的工作集。

## 功能

- 显示总内存、已用内存、可用内存和使用率。
- “一键释放”遍历当前登录会话的普通进程。
- 优先调用 `EmptyWorkingSet`，失败时回退到 `SetProcessWorkingSetSize(-1, -1)`。
- 主动跳过系统核心进程、Windows 壳层关键组件、跨会话进程和工具自身。
- 单个进程权限不足或已退出时继续处理，并在日志中汇总。
- 显示释放前后数值和本次可用内存增量。
- 可打开始终置顶、可拖动的迷你悬浮窗，显示使用率和可用内存。
- 悬浮窗每 2 秒刷新显示，并提供手动“释放”按钮；不会自动执行清理。
- 关闭主窗口时转入 Windows 通知区域后台运行，已打开的悬浮窗保持显示。
- 托盘图标支持恢复主界面、显示悬浮窗和彻底退出程序。
- 启动时由 Windows 显示 UAC 提示，确认后以管理员身份运行。
- EXE、主窗口、任务栏和托盘图标使用统一的蓝色内存芯片图标。
- 其他游戏或软件取得前台焦点时，悬浮窗自动下沉；返回桌面或本工具时恢复悬浮。
- 悬浮窗提供“自动”“置于顶层”“置于底层”按钮，可随时手动覆盖自动层级。
- 软件只允许运行一个实例；重复启动时提示软件可能已在后台运行，然后退出第二个实例。

## 使用

直接双击 `内存整理工具.exe`。Windows 会显示用户账户控制（UAC）提示；选择“是”后程序以管理员身份运行，选择“否”则不会启动。点击主界面的“悬浮窗”可打开迷你窗口；拖动标题区域可移动，右上角方框按钮返回主界面，`×` 只关闭悬浮窗。

点击主窗口右上角 `×` 后，主界面会隐藏到 Windows 右下角通知区域，程序不会退出，已打开的悬浮窗也不会关闭。双击托盘图标可恢复主界面；右键托盘图标并选择“退出”，才会同时关闭主界面和悬浮窗并结束程序。托盘图标显示在任务栏还是“隐藏的图标”面板由 Windows 设置决定。

软件不允许多开。如果已有实例正在运行，再次双击 EXE 会提示“软件已经在运行”，随后只关闭新启动的第二个进程；原来的后台实例、主界面和悬浮窗不会受到影响。

悬浮窗只在桌面或本工具位于前台时保持置顶。如果切换到游戏、浏览器或其他软件，悬浮窗会自动取消置顶并移到该软件后面；切回桌面或内存整理工具后会自动恢复。此功能只读取 Windows 当前前台窗口，不读取其他软件内容。

悬浮窗底部的“自动”按钮使用上述自动逻辑；“置于顶层”会强制保持在其他窗口上方；“置于底层”会强制移动到其他窗口后方。关闭并重新打开悬浮窗后默认恢复为“自动”。

Windows 本身会自动管理内存。整理工作集不会增加物理内存，也不等于修复内存泄漏；被移出的内存页可能在程序继续使用时重新载入。因此建议仅在内存紧张或排查占用时手动使用。

## 从源码构建

需要 Windows 和 .NET 6 SDK：

```powershell
dotnet build .\MemoryCleaner.csproj -c Release
```

生成单文件、包含运行时的 x64 EXE：

```powershell
dotnet publish .\MemoryCleaner.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true
```

发布结果位于 `bin\Release\net6.0-windows\win-x64\publish`。

## 安全边界

- 不结束任何进程。
- 不停止或禁用任何服务。
- 不修改注册表、启动项或系统配置。
- 不提供定时循环清理。
- 管理员权限只用于访问符合过滤条件的进程，不会扩大到结束进程、修改服务或更改系统配置。
- 由于后台活动会持续改变内存占用，前后差值是瞬时参考值，不是性能提升保证。
